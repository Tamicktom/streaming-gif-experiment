Lab

Streaming GIF experiment

GIF is a file format, not a streaming protocol. This lab asks whether a browser <img> can decode and animate a GIF while the HTTP response is still open and new frames keep arriving.

Home Experiment 1 Experiment 2

Why this exists

After the GIF89a header and colour table, each frame is a self-contained block. In principle a decoder can paint the first frame and keep appending later ones before the trailer byte 0x3B arrives. Real browsers, HTTP buffering, and image decoders may not play along.

The server starts a valid GIF, then sends one complete frame per chunked HTTP/1.1 body piece. Trailer policy and frame interval are knobs, not assumptions.
